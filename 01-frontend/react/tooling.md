# React — tooling

| E2E | Playwright |
| API mocking | MSW |
| Accessibility | axe-core, eslint-plugin-jsx-a11y |
| Performance | Lighthouse, React DevTools Profiler |
| Lint | ESLint with react-hooks plugin |
