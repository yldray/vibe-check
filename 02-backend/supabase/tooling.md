# Supabase — tooling

| Purpose | Tool |
|---|---|
| Local stack | Supabase CLI (`supabase start`) |
| RLS and SQL tests | pgTAP via `supabase test db` |
| Schema changes | `supabase db diff`, migrations in the repo |
| Security review | Dashboard → Advisors → Security Advisor |
| Types | `supabase gen types` |
